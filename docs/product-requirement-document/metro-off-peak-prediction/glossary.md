# Glossary — metro-off-peak-prediction

| Term | Chinese | Definition |
|------|---------|-----------|
| Off-peak window | 離峰時段 | The time window per line/station/day when ridership is below the congestion threshold; derived daily from previous day's data |
| Commitment pledge | 卡位承諾 | Game A: user stakes points and pledges to enter during the off-peak window |
| Ridership prediction | 運量猜猜樂 | Game B: user predicts today's ridership count/range for a specific line/station window |
| Combo multiplier | 串關獎勵 | The 1+1>2 bonus triggered when both Game A and Game B succeed in the same day |
| Carbon-reduction fund pool | 減碳基金池 | The pool that accumulates forfeited commitment stakes; displayed as a community metric |
| Stake | 下注點數 | Points committed in Game A; returned with multiplier on success or forfeited on failure |
| Off-peak entry | 離峰進站 | An MRT gate tap that occurs within the day's off-peak window |
