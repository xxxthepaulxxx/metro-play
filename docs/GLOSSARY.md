# Glossary

| Term (zh-TW) | Term (en) | Definition |
|---|---|---|
| 盲盒 | Blind Box | A mystery package purchased with MRT points that reveals a random destination station, hidden spot, and merchant discount. Core mechanic of Module 2. |
| 私房景點 | Hidden Spot | A lesser-known scenic location or local business near an MRT station, surfaced to users through the blind box reveal. |
| 商家折扣 | Merchant Discount | A guaranteed coupon or percentage-off offer from a station-adjacent merchant, included in every blind box. |
| 開盒驚喜 | Unboxing Surprise | The animated reveal moment when a blind box is opened, designed as the emotional peak of the Module 2 experience. |
| 忠誠度等級 | Loyalty Tier | A persistent rank (Bronze / Silver / Gold / Platinum) determined by cumulative off-peak points. Each tier grants a passive multiplier to future session rewards. |
| 累積點數 | Cumulative Points | Lifetime total of off-peak points earned across all sessions. Only increases (no decay). Sole input to tier evaluation. |
| 被動倍率 | Passive Multiplier | Per-tier scaling factor applied automatically to session rewards at settlement. |
| 升級 | Tier-Up | The event of crossing a tier threshold. Triggers the unlock animation. |
